### エントリ 0003（2026-07-18）
- 議論の契機: 非対話環境における、前回定めた衝突時の挙動を再検討するため。適用対象の親子関係から決定的な解決方法を導け、ユーザー入力なしに一度の実行で完了することが期待される環境では、検証を停止することが望ましくない場合があります。
- 発見事項 / トレードオフ: 非対話の CI やバッチ実行では質問に回答できないため、親子衝突のすべてで停止すると、スコープの具体性による明示的な順序がある場合でも一度の実行が失敗します。警告を出して狭いスコープの子決定を選ぶことは、親を黙って上書きすることとは異なります。診断には対象パス、決定 ID、衝突した制約、適用したフォールバックを含められます。対話実行では、判断が必要な衝突について引き続きユーザーへ質問します。このフォールバックは、親子関係が明確な衝突に限定します。同一スコープの重複、兄弟間の曖昧性、決定 ID が不明な場合、または決定的なスコープ関係がない衝突は、安全な自動選択肢がないため、引き続き検証失敗とします。
- 現時点の結論: 親子衝突の規則を変更し、対話実行では解消に必要な詳細を示してユーザーへ質問し、非対話実行ではスコープ関係が明確な場合に警告を出して狭いスコープの子決定を適用し、作業を継続します。解決不能な曖昧性は検証失敗として残し、診断、対話的解決、非対話フォールバックを明示する決定を追加します。
- DECISIONS.yml への昇格: promoted -> agent-012-3-cross-scope-conflict, agent-012-5-actionable-conflict-resolution
